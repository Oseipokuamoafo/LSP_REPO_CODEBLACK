# Question 2 — Design Explanation

The Template Method pattern is used here by defining a fixed workflow in the `generateReport()` method inside the abstract `Report` class. This method calls `loadData()`, `formatHeader()`, `formatBody()`, and `formatFooter()` in a set order that never changes. The abstract methods are the variable steps — `StudentReport` and `CourseReport` each provide their own implementations of those methods to produce report-specific output. The `generateReport()` method is marked `final` to prevent subclasses from altering the workflow. This design separates the invariant structure of report generation from the parts that vary by report type, making it easy to add new report types without changing any existing code.
